# 抖音 Loon 广告净化（谨慎版）

## 安装

1. 在 Loon「配置 → 插件 → + → URL」安装 `https://raw.githubusercontent.com/IMAiCool/Loon/main/Douyin/Douyin_Clean.plugin`。脚本使用同仓库固定 Raw 地址，添加插件后无需单独安装 `.js`。
2. 启用 Loon MitM，安装并信任证书，检查插件的主机名已纳入 MitM。启用 HTTPS 解密前先了解其影响。
3. 先启用推荐流开关，确认正常后逐一启用关注、同城和搜索。开屏开关默认关闭。
4. 如已安装其他抖音改写插件，先停用重叠的响应脚本，再检查本插件是否生效；Loon 对同一个响应至多运行一个响应脚本。

## 处理范围

仅匹配 `aweme.snssdk.com` 和 `*.amemv.com` 的指定信息流、搜索响应，按明确的 `is_ads`、`is_ad`、`raw_ad_data`、`ad_id`、`ad_data` 标记移除列表项。不会改动 Cookie、Token、请求头、登录、验证码、私信、评论、点赞和视频播放接口。不会拦截统计域名，也不处理没有明确标记的商业内容。

开屏实验开关只匹配 `/api/ad/v*/splash/` 的 JSON 响应中有广告标记的条目；该接口、响应结构及当前 iOS 抖音版本适配尚未实机验证。**无法删除已经缓存在 iOS App 本地的开屏素材**。Loon 的脚本也不能直接禁止 App 写入本地缓存。

## 检查与排障

- 在 Loon 的脚本日志查找 `[Douyin Clean] feed removed=N` 等记录。没有记录时检查插件、MitM、证书和接口匹配；记录 `removed=0` 不会显示，因为原响应直接放行。
- 广告仍出现：可能来自本地缓存、未覆盖的新版接口、加密/非 JSON 响应或无明确广告标记；需要该次请求的**脱敏** URL、响应字段样本和抖音 App 版本来补适配。不要分享 Cookie、Token、手机号或完整请求包。
- 页面加载异常：关闭对应开关、重启抖音；如装有同类插件，先排查响应脚本冲突。

语法依据：Loon 官方插件、Script 与 Script API 文档；接口参考既有社区配置，实际生效仍取决于抖音版本。
